How we score.

Same queries, same judges, same rubric, every vendor. Raw scores are on the data page.

Queries

queries in categories, authored for this benchmark and published with the export.

Category Queries What it tests

Breaking-news queries carry no fixed answer. They are written in current form and graded on source recency and internal consistency.

Vendors

The published set is the vendors whose terms allow this comparison. Vendors whose terms restrict third-party benchmarking are not listed.

Vendor Returns Notes

How each API is called

  • Exa - /search, default search type, with contents.text requested so the judge sees snippet text, matching the other vendors.
  • Perplexity - sonar, output capped at 2048 tokens.
  • Serper - /search, default settings.
  • Linkup - standard depth.
  • You.com - the search endpoint.

Every response is truncated to the top results before a judge sees it.

Judges

Three models from three labs score every response against one rubric. The published score is the median.

Model versions are pinned. Changing one is a methodology change.
