# SearchBench

A project directory for building SearchBench: a free, continuously-updated, neutral public benchmark of web-search/retrieval APIs used by AI agents (Tavily, Exa, Brave, Serper, You.com, Perplexity, and others), plus a monetized BYOK routing layer built on top of the benchmark's own data. This is the mechanism speko.ai (a confirmed Y Combinator Summer 2026 company) uses for voice AI, generalized to web search — no funded or launched product currently combines a neutral cross-vendor benchmark with a monetized router in this category.

## How to use this directory

Point Claude Code at this folder and let it read `CLAUDE.md` first — that file is written specifically as an operating guide for an AI coding assistant picking up this project, and it links out to every other document here for the right context at the right time. The `docs/` folder is the complete research record everything else is built on:

`docs/01-product-spec.md` covers what SearchBench is, why now, and what ships in v1. `docs/02-competitive-landscape.md` covers the full competitive sweep. `docs/03-legal-and-vendor-terms.md` covers vendor terms of service, the real legal risk around benchmarking clauses, and the naming/trademark situation — read this one carefully before building anything that touches vendor APIs. `docs/04-benchmark-methodology.md` covers the query taxonomy, dataset choices, and LLM-judge design including bias mitigations. `docs/05-architecture.md` covers the recommended technical build. `docs/06-business-model.md` covers pricing and unit economics. `docs/07-build-plan.md` covers the week-by-week plan mapped against Founders Inc's rolling application process and YC's actual (and projected) deadlines. `docs/08-risks-and-open-questions.md` is the honest counterweight to everything else — read it whenever something elsewhere in this directory seems too clean. `docs/09-sources.md` has every citation this research rests on.

## Status as of 2026-07-30

All research gaps identified after the initial idea search and the Speko.ai comparison have been closed as thoroughly as they can be without primary legal counsel or direct vendor outreach. No code has been written yet. The single most important new finding from this final research pass, not previously known: two vendors in the target set have terms of service that explicitly prohibit benchmarking without written consent, and two more have broad language that could plausibly be read to cover it — this is now the top item in `docs/08-risks-and-open-questions.md` and shapes the recommended v1 vendor scope in `docs/01-product-spec.md`. The timeline is also now concrete: YC's Fall 2026 deadline has already passed, Winter 2027's deadline isn't published yet (recheck in September), and Founders Inc has no deadline at all — which is why the build plan recommends applying to Founders Inc as soon as an MVP is live rather than waiting.

## What this directory is not

It is not a finished legal clearance, a finished trademark search, or a substitute for an actual attorney reviewing the benchmark methodology before public launch — `docs/03-legal-and-vendor-terms.md` says this explicitly and it's worth repeating here. It is not a guarantee that this idea gets into Founders Inc or YC — `docs/08-risks-and-open-questions.md` is honest about the real odds. It is the most thorough research pass that could be done from open sources as of 2026-07-30, organized so that building can start immediately on the parts that are solid, while the parts that still need a human decision (the final product name, whether to pursue vendor consent conversations, when to spend money on a lawyer) are flagged clearly rather than quietly resolved by guessing.
