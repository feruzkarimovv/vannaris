**What are you currently working on?** (888 chars)

Vannaris, an independent benchmark of the web-search APIs that AI agents call: Exa, Perplexity, Serper, You.com, Linkup. Same queries, every vendor, scored by three LLM judges from three labs, published free with the raw data at vannaris.com. Three weeks published, and as of this Monday it runs itself on a schedule instead of me starting it. The finding: the cheapest API returns 92-98% of the category leader's quality on four of six query types at a seventh of the price. I started this to build a router that picks the best vendor per query, then measured that perfect per-category routing beats always calling the best single vendor by 0.08 points out of 10. So I killed the router and kept the instrument. Now I'm building a harder query set, because the current one is saturating, and the business is private evals: the same harness pointed at a customer's own production queries.
